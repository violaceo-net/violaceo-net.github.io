Privacy Policy – Shorts

Ultimo aggiornamento: 14 novembre 2026

Questa informativa descrive come l'applicazione Shorts (di seguito "l'app") accede, usa, conserva e protegge i dati del tuo account Google/YouTube. L'app è uno strumento personale, eseguito solo sul PC del suo sviluppatore, che usa le YouTube Data API v3 per caricare gli short sui canali YouTube del proprietario.

1. Permesso richiesto e dati trattati

L'app richiede un solo ambito OAuth 2.0: https://www.googleapis.com/auth/youtube.upload, e lo usa esclusivamente per caricare video tramite il metodo videos.insert delle YouTube Data API v3.

Gli unici dati trattati sono quelli che l'app invia a YouTube al momento del caricamento:

  • il file video dello short;
  • i metadati del video: titolo, descrizione e tag.

L'app non legge statistiche, informazioni del canale, playlist, commenti o altri dati dell'account, e non modifica né cancella video già pubblicati. Non accede inoltre a email, contatti, cronologia di visione o altri dati dell'account Google.

2. Come vengono usati i dati

I dati sono usati esclusivamente per caricare gli short sul canale del proprietario. Non sono usati per pubblicità, profilazione o addestramento di modelli di intelligenza artificiale.

3. Conservazione dei dati

  • I token OAuth (di accesso e di aggiornamento) sono salvati solo in locale, sul PC su cui gira l'app.
  • Non esiste alcun server dell'app: nessun dato viene inviato a server propri o di terzi, ad eccezione delle chiamate dirette alle API di YouTube necessarie per il caricamento.
  • Cancellando i file locali dei token, questi vengono eliminati definitivamente.

4. Condivisione con terzi

I dati non vengono venduti, né ceduti, né condivisi con terzi per nessuno scopo. L'unico destinatario dei dati è YouTube, tramite le API ufficiali, per eseguire il caricamento richiesto.

5. Google API Services User Data Policy e Limited Use

L'uso e il trasferimento ad altre app delle informazioni ricevute dalle API di Google da parte di Shorts rispettano la Google API Services User Data Policy, inclusi i requisiti di Limited Use (uso limitato).

In particolare, i dati ottenuti dalle API di Google:

  • sono usati solo per fornire o migliorare le funzioni dell'app visibili all'utente;
  • non sono trasferiti a terzi, salvo quanto necessario per fornire tali funzioni, per rispettare la legge o nell'ambito di una fusione o acquisizione;
  • non sono usati per pubblicità, né per determinare l'affidabilità creditizia o per finalità di prestito;
  • non sono letti da persone, salvo con consenso esplicito dell'utente, per motivi di sicurezza o per obblighi di legge.

6. Servizi YouTube API

L'app usa i servizi YouTube API. Usando l'app accetti i Termini di servizio di YouTube. Il trattamento dei dati da parte di Google è regolato dalle Norme sulla privacy di Google.

7. Come revocare l'accesso

Puoi revocare in qualsiasi momento l'accesso dell'app al tuo account dalla pagina https://myaccount.google.com/permissions (Account Google → Sicurezza → App e servizi di terze parti). Dopo la revoca l'app non può più caricare video; i token salvati in locale smettono di funzionare e possono essere cancellati.

8. Modifiche a questa informativa

Eventuali modifiche saranno pubblicate su questa pagina, con l'aggiornamento della data in alto.

9. Contatti

Per domande su questa informativa o sui tuoi dati: givazzo@gmail.com

Privacy Policy – Shorts

Last updated: November 14, 2026

This policy describes how the Shorts application ("the app") accesses, uses, stores and protects data from your Google/YouTube account. The app is a personal tool, running only on its developer's PC, that uses the YouTube Data API v3 to upload Shorts to the owner's YouTube channels.

1. Permission requested and data processed

The app requests a single OAuth 2.0 scope: https://www.googleapis.com/auth/youtube.upload, and uses it solely to upload videos through the videos.insert method of the YouTube Data API v3.

The only data processed is what the app sends to YouTube at upload time:

  • the Short's video file;
  • the video's metadata: title, description and tags.

The app does not read statistics, channel information, playlists, comments or any other account data, and does not edit or delete videos that are already published. It also does not access email, contacts, watch history or any other Google account data.

2. How the data is used

Data is used solely to upload Shorts to the owner's channel. It is not used for advertising, profiling or training artificial intelligence models.

3. Data storage

  • OAuth tokens (access and refresh) are stored only locally, on the PC where the app runs.
  • The app has no server: no data is sent to the developer's or any third-party servers, except for the direct calls to the YouTube APIs required for uploading.
  • Deleting the local token files permanently removes them.

4. Sharing with third parties

Data is not sold, transferred or shared with third parties for any purpose. The only recipient of the data is YouTube, through the official APIs, to perform the requested upload.

5. Google API Services User Data Policy and Limited Use

Shorts' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

In particular, data obtained from Google APIs:

  • is used only to provide or improve user-facing features of the app;
  • is not transferred to third parties, except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition;
  • is not used for advertising, or to determine creditworthiness or for lending purposes;
  • is not read by humans, except with the user's explicit consent, for security purposes, or to comply with applicable law.

6. YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

7. How to revoke access

You can revoke the app's access to your account at any time at https://myaccount.google.com/permissions (Google Account → Security → Third-party apps & services). After revocation the app can no longer upload videos; locally stored tokens stop working and can be deleted.

8. Changes to this policy

Any changes will be published on this page, and the date at the top will be updated.

9. Contact

For questions about this policy or your data: givazzo@gmail.com
